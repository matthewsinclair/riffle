# Riffle whiteboard roster

This file is the roster of the whiteboard under `intent/whiteboard/`: the Team Profiles it declares and every seat registered on it. `intent wb init --apply` renders everything above the block at the end from the declared profiles and the store, so an edit there is undone by the next render and `intent doctor` reports it. The project's own notes go inside the block, which every render carries as it is.

## Profiles

This whiteboard declares the base profile `solo`. `intent wb profile show <name>` prints a profile.

## Route to hv

hv is reached through the mediator, `gc` (Generalist Claude), the one reader of hv's inbox. What the profile asks of every other seat:

You reach hv through the mediator, and only through it: send your request to the mediator and never write to hv's inbox yourself. When hv rules to you directly, pass the ruling to the mediator, who records it. No seat waits idle on hv: hold only the work that depends on the answer, and carry on with the rest.

## Terms

The words this roster uses (seat, mediator, hat, pen, Desk) are defined once, in the terms document every profile shares: `intent wb profile terms` prints it.
